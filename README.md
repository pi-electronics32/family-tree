
# Family Legacy — Interactive Family Tree

A Flask + SQLite family-tree website based on the family information entered so far.

## 1. Install Python
Use Python 3.10+.

## 2. Open this folder in Terminal / CMD

```bash
cd family_legacy
```

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Run

```bash
python app.py
```

## 5. Open in browser

Go to:

http://127.0.0.1:5000

## Features
- Illustrated family-tree interface
- Search family members
- Click a person for details
- Add new family members
- Add parent/spouse relationships
- SQLite database
- JSON API at /api/tree

## Important
This is a local/private prototype. For a public family website, add authentication and HTTPS before publishing it online.
